A basic HTML tool that runs locally in your web browser. It does not log in to Instagram, connect to your account, request your password, or access any account data other than the follower and following lists that you personally select from your Instagram data export.

How it works

Instagram can provide you with an official copy of your followers and the accounts you follow. This tool reads those two HTML lists on your own computer and compares them. It then shows the accounts that appear in your Following list but not in your Followers list.

How to get the required files from Instagram

  1. Open Instagram's official Accounts Center export page: Export your information.
  2. Log in to Instagram if requested.
  3. Choose Create export.
  4. Select the Instagram profile you want to check.
  5. Choose Export to device.
  6. In the information selection screen, first deselect all options, then select only Followers and following. Depending on the current Instagram interface, this may appear under a section such as Following, Threads and connections.
  7. Set the date range to All time.
  8. Choose HTML as the file format.
  9. Start the export request. The time needed for Instagram to prepare the file varies depending on the export options and amount of data selected. In most cases, when exporting only the follower/following information, the file should be ready in less than 10 minutes.
  10. When Instagram makes the export available, download the ZIP file and extract it.
  11. After extracting the ZIP file, the files you need are usually located in connections/followers_and_following. Inside that folder, the only files you should load into this tool are the followers file and the following file (normally followers_1.html or followers.html, and following.html).
  12. Drag those followers and following HTML files into the box above.
  13. Click Compare.
Privacy: all processing is performed locally inside this HTML page. The selected files are not uploaded anywhere by this tool. You can even disconnect from the Internet before comparing the files. An Internet connection is only needed if you later click a username to open that Instagram profile.
